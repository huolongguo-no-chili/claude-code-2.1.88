# Claude Code

![](https://img.shields.io/badge/Node.js-18%2B-brightgreen?style=flat-square) [![npm]](https://www.npmjs.com/package/@anthropic-ai/claude-code)

[npm]: https://img.shields.io/npm/v/@anthropic-ai/claude-code.svg?style=flat-square

Claude Code 是一款代理式编程工具，它在你的终端中运行，能够理解你的代码库，并通过自然语言命令帮助你更快地编写代码——执行日常任务、解释复杂代码、处理 Git 工作流程。你可以在终端、IDE 中使用它，或者在 GitHub 上 @claude。

**了解更多：[Claude Code 官网](https://claude.com/product/claude-code)** | [文档](https://code.claude.com/docs/en/overview)

<img src="https://github.com/anthropics/claude-code/blob/main/demo.gif?raw=1" />

## 快速开始

1. 安装 Claude Code：

```sh
npm install -g @anthropic-ai/claude-code
```

2. 进入你的项目目录，然后运行 `claude`。

## 报告问题

我们欢迎你的反馈。在 Claude Code 中使用 `/bug` 命令直接报告问题，或者提交 [GitHub Issue](https://github.com/anthropics/claude-code/issues)。

## 加入 Discord 社区

加入 [Claude 开发者 Discord](https://anthropic.com/discord)，与其他使用 Claude Code 的开发者交流。获取帮助、分享反馈、与社区讨论你的项目。

当你使用 Claude Code 时，我们会收集反馈数据，包括使用数据（如代码接受或拒绝情况）、相关的对话数据，以及通过 `/bug` 命令提交的用户反馈。
